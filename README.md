Screenshots for the py2Dmol plugin pull requests. Not part of the library.

All are from the browser probes in tests/ (plugin_browser.py, plugin_rows_browser.py, volume_browser.py),
rendered by Chromium with a software WebGL2 rasteriser (SwiftShader) on 1CRN, not on a GPU. The shells,
cubes and fields are synthetic test data, not real free energies.
